About

Caliptra uses SHA-384 hashes of the vendor and owner public key structures to validate firmware signatures. These hashes are programmed into fuses (or OTP in MCU subsystem mode). The vendor_pk_hash is the SHA-384 of the full ImageVendorPubKeys structure (4 ECC keys + 4 LMS keys + 4 MLDSA keys = 10,944 bytes), and the owner_pk_hash is the SHA-384 of the OwnerPubKeyConfig structure (1 ECC key + 1 LMS key + 1 MLDSA key = 2,736 bytes).

All values below are pre-filled with Caliptra's test/fake keys. Edit any field and the hash updates automatically.
