Debug unlock calculator

Build debug unlock mailbox commands for the emulator. Manufacturing unlock sends a shared-secret token. Production unlock is a challenge-response signed with ECC P-384 and ML-DSA-87.

To send one, start the emulator with Debug intent on, pick the command in its Mailbox panel, switch the input to Raw hex and paste the payload. The emulator adds the checksum, so use Copy payload; Copy command includes the checksum for use with other tools.

Manufacturing debug unlock

Send a 32-byte token with MANUF_DEBUG_UNLOCK_REQ_TOKEN (0x4D445554). The ROM hashes the token with SHA-512 and compares the result with the fuse value. The default tokens below are the same for Caliptra 2.0 and 2.1.

Caliptra-only mode

The token that matches the emulator's default fuses.

SHA-512 of the token (the 64-byte fuse value)
Mailbox command, with checksum

Caliptra + MCU mode

The token that matches the emulator's default OTP contents (DEFAULT_MANUF_DEBUG_UNLOCK_RAW_TOKEN in caliptra-sw's hardware model).

SHA-512 of the token
Mailbox command, with checksum

Production debug unlock

A challenge-response in four steps, signed with ECC P-384 and ML-DSA-87. It runs in the emulator's Caliptra + MCU mode. The hash of the two public keys must be in OTP for the unlock level you request: paste it into that level under Fuse overrides → Production debug unlock PK hashes on the emulator page before starting it.

2. Request

Send PRODUCTION_AUTH_DEBUG_UNLOCK_REQ (0x50445552) to get a challenge.

Mailbox command

3. Challenge

Paste the emulator's response to PRODUCTION_AUTH_DEBUG_UNLOCK_REQ.

4. Token

Signs SHA-384(uid || level || reserved || challenge) with ECC and SHA-512(uid || level || reserved || challenge) with MLDSA, then builds the PRODUCTION_AUTH_DEBUG_UNLOCK_TOKEN (0x50445554) command.

Token command (7504 bytes)
