PQ.DevID identity (ML-DSA-87)

Caliptra 1.3 runtimes add a post-quantum device identity, PQ.DevID: an ML-DSA-87 key pair derived from a seed the SoC sends with SET_PQ_SEED. Caliptra 1.x has no ML-DSA hardware, so the runtime computes ML-DSA in software; each step below takes about 10 to 60 million emulated cycles. Run the emulator until the runtime is listening for mailbox commands, then provision the seed first.

Pre-filled with the test seed caliptra-sw's own tests use. PQ.DevID is derived from the seed alone, so the same seed always gives the same key pair.
